# Experiment No. 9 — Use Process Explorer to Identify Suspicious Processes

## Aim

To use Process Explorer to examine running processes in a Windows system and identify potentially suspicious processes.

## Description

Process Explorer is a powerful Windows system-monitoring tool developed by Microsoft Sysinternals. It provides detailed information about running processes, including process IDs, parent-child relationships, CPU usage, memory usage, executable paths, digital signatures, and network activity.

It can be used for system monitoring, troubleshooting, security analysis, and preliminary malware investigation.

## Requirements

- Windows Operating System
- Microsoft Sysinternals Process Explorer
- Administrator privileges
- Internet connection

## Tool Used

**Microsoft Sysinternals Process Explorer**

Official Website:

https://learn.microsoft.com/en-us/sysinternals/downloads/process-explorer

---

# Procedure
Download Process Explorer

1. Open a web browser.
2. Visit the official Microsoft Sysinternals Process Explorer website.
3. Download the Process Explorer ZIP file.
4. Extract the downloaded ZIP file.

The extracted folder contains files such as:

procexp.exe
procexp64.exe
